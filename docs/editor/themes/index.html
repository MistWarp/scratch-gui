Themes

MistWarp's appearance is themeable: a light or dark editor, an accent colour, the colours of the blocks, and fully custom themes you can build and share. This page explains where each of these lives.

Editor theme and accent​

The overall light or dark look and the accent colour apply across all of MistWarp (the editor and the community site), so they live in your MistWarp account settings rather than the editor's own window. Open the settings window, go to the Theme page, and follow Edit my MistWarp settings to change them on the site.

Accent colours are grouped into plain colours, a set of pride flags, and richer gradient accents (such as Sunset, Ocean, and Aurora). Your choice is saved to your account and syncs across your devices when you are signed in.

Block colours​

The editor's Theme page sets the colour scheme of the blocks themselves, separately from the interface theme:

  • Original: the standard Scratch block colours.
  • High Contrast: bolder, higher-contrast colours for readability.
  • Dark (Beta): darker block colours to match a dark editor.

For finer control over individual category colours, Customize in Addon Settings opens the block-theme addon, where each category's colour can be set by hand.

Custom themes​

Custom themes bundle a whole look (accent, light or dark mode, block colours, wallpaper, and fonts) under a name so you can switch between them or share them. The custom themes manager lets you:

  • Create from your current look: snapshot everything you have set into a named theme.
  • Build a gradient theme: design a gradient accent in the gradient builder (below).
  • Import and export: load themes from a JSON file, or export your whole library as one file.
  • Browse the marketplace: open the WarpTheme community theme collection and add themes to your library.

Each saved theme can be applied, edited, exported on its own, or deleted.

The gradient builder​

The gradient builder designs a gradient accent for a custom theme:

  • Colour stops: drag stops along the preview bar to reposition them, pick each stop's colour, and add or remove stops (two to eight).
  • Direction: set the gradient angle with a slider or one of eight preset arrows.
  • Quick presets: start from a ready-made gradient.
  • Primary colour: the solid colour derived from the gradient, used for UI accents.

Preview applies the gradient live so you can see it before saving, and toggling preview off restores your previous theme.

Bundling a theme with a project​

A project can carry its own theme. When you save, MistWarp can store your current theme in the project (via Store settings in project on the settings General page, with Store theme in project ticked). When someone opens that project in the editor, MistWarp asks whether to apply the project's theme or keep their own, with a "do not ask again" option. On a project's community page the stored theme is applied automatically to the player.
